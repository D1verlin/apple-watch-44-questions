Дайте определение понятию «переменная». Опишите разницу между объявлением и инициализацией переменной.

Переменная – это именованная область памяти, предназначенная для хранения данных определенного типа, которые могут изменяться в процессе выполнения программы

Объявление - создание переменной. Мы сообщаем компилятору имя переменной и тип данных, которые она будет хранить. В этот момент выделяется память, но данных в ней ещё нет.

Инициализация - присвоение переменной первого (начального) значения. Только после этого переменную можно безопасно использовать в расчетах или выводить на экран.

Переменные в C# правильно именовать при помощи стиля lowerCamelCase, при котором первое слово в названии всегда начинается с маленькой буквы, а каждое последующее слово начинается с заглавной. Употребление других символов кроме буквенных не допускается.

Безопасные (неявные) преобразования: byte - short - int/char - long - float - double - decimal (частично), ushort - int, uint - long, ulong - float/double, любые типы - object

Технически, char занимает тот же объем памяти что и int, и char может быть представлен в виде int и обратно, меняя представление с символа(char) на код этого символа в таблице Unicode(UTF-16).

Оператор множественного выбора - это управляющая конструкция, которая позволяет программе выполнять один из нескольких вариантов действий в зависимости от значения определённой переменной или выражения.

В C# такой оператор один единственный - switch. Он бывает двух видов, но тут требуется конкретно switch-case.

switch (выражение) {
    case значение:
        // код, который выполнится если `выражение` = `значение`
        break;
    case значение2:
        // код, который выполнится если `выражение` == `значение2`
        break;
    default:
        // код, который выполнится если значение выражения не
        // равно ни одному из значений написанных рядом с case
        break;
}

Дайте определение понятию «цикл с предусловием». Опишите синтаксис оператора while и поясните принцип его работы.

Цикл с предусловием – управляющая конструкция, которая выполняет блок кода несколько раз, проверяя условие выполнения до начала каждой итерации. Если при первой проверке условие оказывается ложным, тело цикла не выполнится ни разу.

while (условие)
{
    // блок кода (тело цикла)
}
  • while — ключевое слово, запускающее цикл.
  • условие — логическое выражение (возвращающее true или false), которое обязательно заключается в круглые скобки.
  • { } — фигурные скобки, ограничивающие тело цикла. Если в теле цикла всего одна инструкция, скобки можно опустить.

Дайте определение понятию «цикл с постусловием». Опишите синтаксис оператора do-while и поясните принцип его работы.

Цикл с постусловием – это циклическая управляющая конструкция, в которой тело цикла выполняется как минимум один раз, а проверка условия выхода происходит после его выполнения.

Если условие оказывается истинным (или в некоторых языках - ложным, в зависимости от синтаксиса), цикл повторяется; если нет - выполнение цикла прекращается, и программа переходит к следующим инструкциям.

do {
    // Тело цикла
} while (условие);
  • do — ключевое слово, обозначающее начало тела цикла.
  • {... } — фигурные скобки, внутри которых записываются исполняемые инструкции (тело цикла). Если инструкция всего одна, скобки можно опустить, но их использование считается хорошим тоном.
  • while — ключевое слово, после которого указывается условие продолжения цикла.
  • (условие) — логическое выражение, которое возвращает true (истина) или false (ложь).

Дайте определение понятию «цикл со счетчиком». Опишите синтаксис оператора for и поясните принцип его работы.

Цикл со счетчиком – это управляющая конструкция, которая повторяет блок команд заданное количество раз, используя специальную переменную (счетчик) для отслеживания текущей итерации.

for (инициализация; условие; изменение) {
    // Тело цикла (выполняемые команды)
}
  • Инициализация: Создание и/или установка начального значения переменной-счетчика (выполняется один раз в самом начале).
  • Условие: Логическое выражение, которое проверяется перед каждой итерацией. Цикл продолжает работать, пока оно возвращает истину (true).
  • Изменение: Обновление счетчика (обычно увеличение или уменьшение на единицу) после каждого выполнения тела цикла.

Перечислите обязательные компоненты, которые указываются внутри круглых скобок в заголовке цикла foreach в языке C#. Опишите синтаксис оператора foreach и поясните принцип его работы.

В заголовке цикла foreach внутри круглых скобок указываются два обязательных компонента: тип и имя переменной цикла (итератора), а также перебираемая коллекция, разделенные ключевым словом in.

foreach ([тип] [имя переменной] in [коллекция])
{
    // Тело цикла
}
  • Тип – тип данных элементов, находящихся в коллекции (можно использовать явный тип, например int, string, либо ключевое слово var, чтобы компилятор определил тип автоматически).
  • Имя переменной — локальная переменная, в которую на каждой итерации цикла будет поочередно копироваться текущий элемент коллекции.
  • Ключевое слово in — обязательный оператор, разделяющий объявление переменной и целевую коллекцию.
  • Коллекция — выражение, возвращающее коллекцию, массив или любой объект, реализующий интерфейс IEnumerable (или имеющий подходящий метод GetEnumerator()).
Теория 11▲ Сетка
Перечислите операторы циклов в С#. Охарактеризуйте применение операторов break и continue в циклах.

В языке C# поддерживаются четыре основных типа операторов цикла:

  • for — цикл с заранее известным числом итераций (содержит инициализацию, условие продолжения и действие для изменения).
  • while — цикл с предусловием (проверяет условие перед каждой итерацией; если оно ложно сразу, тело цикла не выполнится ни разу).
  • do-while — цикл с постусловием (сначала выполняет тело цикла хотя бы один раз, а затем проверяет условие в конце).
  • foreach — цикл для перебора коллекций, массивов и объектов, реализующих интерфейс IEnumerable (предоставляет удобный доступ к каждому элементу по порядку).

Оператор break - полностью прекращает выполнение ближайшего внешнего цикла (или конструкции switch) и передает управление коду, который идет сразу за ним

Оператор continue - пропускает оставшуюся часть кода в теле текущей итерации и сразу переходит к следующему шагу цикла (вычислению условия или шага итератора)

Дайте определение понятию «индекс элемента массива». Опишите способ объявления и инициализации двумерного массива.

Индекс элемента массива - порядковый номер или значение (чаще всего целое неотрицательное число), которое однозначно определяет местоположение конкретного элемента в общей последовательности массива и обеспечивает прямой доступ к нему.

В C# двумерные массивы бывают двух типов: прямоугольные (размерность задается через запятую [,]) и ступенчатые (массивы массивов [][]).

// Прямоугольный двухмерный массив
int[,] matrix = new int[3, 4];

// Прямоугольный двухмерный массив с инициализацией
int[,] matrix = new int[2, 3]
{
    { 1, 2, 3 }, // Строка 0
    { 4, 5, 6 }  // Строка 1
};
Теория 14▲ Сетка
Опишите назначение класса System.Array. Перечислите его основные методы и свойства и укажите их назначение.

System.Array - абстрактный класс, от которого наследуются все массивы, он определяет базовые методы поведения массивов.

Основные свойства:

  • Length - возвращает общее количество элементов во всех размерностях массива.
  • LongLength - возвращает общее количество элементов в виде 64-битного целого числа (long), что необходимо для очень больших массивов.
  • Rank - возвращает размерность (количество измерений) массива (например, 1 для одномерного, 2 для двумерного).

Основные методы:

  • IndexOf - ищет первое вхождение указанного элемента в одномерном массиве и возвращает его индекс (или -1, если элемент не найден).
  • Find / FindLast - возвращают первый или последний элемент, удовлетворяющий условию заданного предиката (лямбда-выражения типа Func<T, bool>).
  • FindAll - находит и возвращает все элементы, которые соответствуют условию.
  • Exists - проверяет, содержит ли массив хотя бы один элемент, соответствующий условию (возвращает true / false).

Методы сортировки:

  • Sort - сортирует элементы одномерного массива по возрастанию.
  • Reverse - меняет порядок элементов в одномерном массиве на обратный.

Модификация и копирование:

  • Clear - очищает массив, сбрасывая его элементы к значениям по умолчанию (0 для чисел, false для bool, null для ссылочных типов). При этом размер массива не меняется.
  • Copy() - копирует диапазон элементов из одного массива в другой.
  • Fill() - заполняет все ячейки (или их часть) указанным значением.

Дайте определение понятию «метод». Опишите разницу между функцией и методом.

Метод - это именованный блок кода, который является членом класса, структуры или интерфейса и содержит последовательность инструкций для выполнения определенного действия

Метод отличается от функции тем, что:

Функция существует вне зависимости от классов и работает только с теми данными, которые переданы ей в качестве аргументов.

Метод принадлежит какому-то классу и всегда имеет доступ к данным объекта этого класса, вызываться он может только через объект класса

Технически в C# не существует глобальных функций и все функции так или иначе привязаны к какому-либо классу. Так что ИНОГДА можно сказать что функция является методом (однако эта функция должна быть статичной и использовать статичные поля класса, чтобы сичтаться СТАТИЧНЫМ методом).

public class Order
{
    public long Number { get; set; }

    public double Price
    {
        get;
        set => field =
            value is >= 0
                ? value
                : throw new ArgumentException(null, nameof(value));
    }

    public string DeliveryPoint { get; set; }

    public Order(long number, double price, string deliveryPoint)
    {
        Number = number;
        Price = price;
        DeliveryPoint = deliveryPoint;
    }

    public static Order FindCheapest(Order[] orders)
    {
        var min = orders[0];
        for (int i = 1; i < orders.Length; i++)
            if (orders[i].Price < min.Price)
                min = orders[i];
        return min;
    }

    public string GetInfo() => $"{Number}, {Price}, {DeliveryPoint}";
}

public class Program
{
    public static void Main()
    {
        var o = new Order(1001, 250.0, "testPoint");

        var orders = new Order[]
        {
            new(1002, 500.0, "testPoint1"),
            new(1003, 50.0, "testPoint2"),
            new(1004, 150.0, "testPoint3"),
        };

        try
        {
            o.Price = -100;
        }
        catch (Exception e)
        {
            Console.WriteLine(e);
        }

        try
        {
            o.Price = -1;
        }
        catch (Exception e)
        {
            Console.WriteLine(e);
        }

        Console.WriteLine($"Order info: {o.GetInfo()}");

        Console.WriteLine($"Cheapest: {Order.FindCheapest(orders).GetInfo()}");
    }
}
